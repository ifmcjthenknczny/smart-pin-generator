# Smart PIN Generator

A minimalist Vue 3 application that generates a random, hard to guess PIN of a chosen length (from 4 to 10 digits) and displays it as large as possible using SVG auto-scaling.

## Overview

- **Responsive SVG Display:** Automatically scales numbers to fit the screen without scrollbars or heavy pixel-measuring JavaScript logic.
- **Dynamic Controls:** Range slider allowing seamless toggling between 4 and 10 digits.
- **Minimalist UI:** Clean black & white design with no external CSS framework dependencies.

## PIN Validation Logic

A generated PIN is considered **non-trivial** only if it meets all of the following criteria:

- **No Zero Start/End:** Must not start with `0`, and must not end with `0` or `5`. (invalid: `0000`, `0369`, `2005`, `1970`)
- **Unique Digits:** All digits within the PIN must be unique. (invalid: `3333`, `6969`, `4220`, `3023`)
- **No Monotonicity:** Cannot be strictly ascending or descending. (invalid: `1268`, `9861`)
- **Not a Date:** Must not match any valid date format for 4, 6, or 8-digit lengths, while year is acceptable if it is not within range 1900 to 2100. `YYMM`, `MMYY` formats are not considered. (invalid: `02042005`, `250609`, `1993`)
- **No Sequential Digits**: Must not contain three or more consecutive ascending or descending digits. (invalid: `1234`, `8769`)

> The app generates a random PIN and validates it against these rules.

## PIN Length vs. Constraint Effectiveness

| PIN Length | Valid Combinations | Percentage of All PINs |
|-----------:|-------------------:|-----------------------:|
|  4 digits  | 3,255              | 32.55%                 |
|  5 digits  | 20,101             | 20.10%                 |
|  6 digits  | 90,629             | 9.06%                  |
|  7 digits  | 389,008            | 3.89%                  |
|  8 digits  | 1,144,472          | 1.14%                  |
|  9 digits  | 2,248,414          | 0.22%                  |

As PIN length increases, the number of valid combinations grows, but their percentage of the total search space decreases. "Digits cannot be repeated" restriction significantly affects the number of possible longer PINs. For generated PINs of 7 digits or higher, knowledge that a it was generated by this tool could make guessing it significantly easier.

## Local Setup

### Prerequisites
- Node.js (v24+ recommended)
- npm

### Getting Started

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/ifmcjthenknczny/smart-pin-generator.git](https://github.com/ifmcjthenknczny/smart-pin-generator.git)
   cd smart-pin-generator

```

2. **Install dependencies:**
```bash
npm install

```


3. **Run development server:**
```bash
npm run dev

```


4. **Build for production:**
```bash
npm run build

```
